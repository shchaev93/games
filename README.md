Новая игра - новая папка и карточка в корневом `index.html`.

## Статистика (Яндекс Метрика, счетчик 114263591)

Счетчик стоит на обеих страницах. Игра отправляет события (цели типа "JavaScript-событие"):

| Идентификатор | Когда |
|---|---|
| `start` | нажали "Играть" |
| `round` | закончился ход (угадан, сдался или время вышло) |
| `round_win` | ход угадан |
| `finish` | дошли до итоговой карточки |
| `finish_early` | завершили игру досрочно |
| `share` | нажали "Поделиться карточкой" |
| `copy` | скопировали итоги |
| `again` | "Сыграть еще" |
| `resume` | продолжили незаконченную игру |

Детали пишутся в параметры визита: `setup` (игроки, фильмов на каждого, режим, таймер, размер колоды), `round` (фильм, результат, очки, сколько подсказок, промахи), `final` (сколько ходов, игроков).
